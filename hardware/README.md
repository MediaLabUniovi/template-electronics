# Documentacion Hardware

Detalles tecnicos de la placa, conexiones y componentes electronicos.

---

## Archivos en este Directorio

- `schematics/`: Esquematicos oficiales en PDF.
- `datasheets/`: Hojas tecnicas de sensores y componentes clave.

---

## Asignacion de Pines (Pinout)

| Senal | Pin MCU | Funcion |
| :--- | :--- | :--- |
| `I2C_SDA` | GPIO 21 | Bus de datos I2C |
| `I2C_SCL` | GPIO 22 | Reloj I2C |
| `STATUS_LED` | GPIO 2 | LED indicador de estado |
