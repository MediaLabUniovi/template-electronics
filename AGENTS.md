# Reglas del Proyecto para Agentes de IA

Este repositorio sigue el estandar oficial de MediaLabUniovi:
https://github.com/MediaLabUniovi/.github/blob/main/NORMAS_PROYECTOS_AGENTES.md

1. **Encabezados Limpios:** Títulos sin emoticonos para preservar slugs.
2. **Paleta Funcional:** Solo '📁', '🛠️', '🔌', '⚠️', '📌' en arboles/enlaces.
3. **Secretos:** Aislar credenciales en 'credentials.h', no commitear claves reales y proveer 'credentials.example.h'.
4. **Commits:** Seguir Conventional Commits ('feat:', 'fix:', 'docs:', 'chore:').
